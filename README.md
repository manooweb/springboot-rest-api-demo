# Spring Boot REST API Demo (Fullstack MVP)

Monorepo containing:
- backend/  : Spring Boot REST API (Java 21)
- frontend/ : Angular UI (Angular 14 + Material)
- bruno/    : Bruno API collections

## Goals
- REST API + validation + error handling
- Database access (JPA/Hibernate) + migrations (Flyway)
- Auth (Spring Security + JWT)
- Docker compose (API + DB)
- Minimal Angular UI
