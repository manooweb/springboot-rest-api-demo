Privacy Policy

Purpose of this policy

This Privacy Policy describes how personal data may be processed when using the projects.manooweb.fr demonstration website and its associated API projects-api.manooweb.fr.

This project is a technical demonstration (MVP) and is not intended for production or commercial use.

Nature of the service

Access to the application is provided through a single shared demonstration account, without user registration.

No personal data is explicitly requested during authentication or normal usage of the service.

Data entered by users

The application contains free-text fields (such as project names, descriptions, task titles or descriptions).

Users may voluntarily enter personal data in these fields. Such data:

  • is not required to use the service,
  • is not requested by the publisher,
  • is not analysed or reused for any purpose other than the demonstration itself.

As the demonstration environment relies on a shared account and a persistent database, any data entered may be visible to other users of the demonstration environment.

Users are therefore strongly advised not to enter personal or sensitive data in the application.

Data persistence

Data entered in the demonstration environment is stored in a database associated with the MVP.

At the current stage of the project, there is no guaranteed automatic data reset. Data may remain stored as long as the demonstration environment is active.

The environment may be reset, modified or deleted at any time without notice.

Authentication data

Authentication is performed using a technical access mechanism based on a JSON Web Token (JWT).

This token is stored in the browser’s local storage for the sole purpose of maintaining the authenticated session.

No authentication data is stored in cookies.

Audience measurement

This website uses Matomo Analytics for audience measurement.

Matomo is configured in a cookie-less mode and does not use tracking cookies.

The collected data is used exclusively for statistical purposes and to improve the technical quality of the project.

Users may object to this audience measurement at any time using the opt-out mechanism provided by Matomo.

User rights

In accordance with applicable data protection regulations, users have the right to:

  • access their personal data,
  • request rectification or deletion of their data,
